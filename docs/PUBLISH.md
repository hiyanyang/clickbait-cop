# Chrome 应用商店上架手册

本手册对应版本 `1.2.0`。跟着做，全程只有三件事需要你本人操作：**付钱、实名、点提交**，其余材料本仓库已备好。

## 0. 概览

| 项 | 内容 |
|---|---|
| 费用 | **一次性 5 美元**，按开发者账号收，不按插件收。以后再上架别的插件不再收费，也没有年费 |
| 总耗时 | 注册付费 10 分钟；身份验证 1–3 天；审核 1–3 天（首次 + 宽 host 权限可能拖到 1–2 周） |
| 申请入口 | <https://chrome.google.com/webstore/devconsole> |
| 商店主页 | <https://chromewebstore.google.com> |

## 2. 注册开发者账号

1. 打开 <https://chrome.google.com/webstore/devconsole>，用 Google 账号登录。
2. 没开两步验证先去 <https://myaccount.google.com/security> 开启，这一步不做后面全卡死。
3. 首次进入会弹出开发者协议 + 注册费：勾选同意 → 支付 **5.00 USD**。支持信用卡，国内双币卡可用。
4. 设置「发布者显示名称」：这是用户在你插件名下方看到的名字，建议用真名或品牌名（比如「闫阳人不辍」），别用一串邮箱号。
5. 添加并验证联系邮箱：**审核结果、拒审原因都发这个邮箱**，用你每天都看的。

## 3. 身份与地址验证（最容易卡的一步）

路径：控制台左侧 **帐户 / Account**。

1. **交易者声明**：选「这是一个交易账户」。你是要公开推广、带业务目的，属交易者。
   - 代价：**法定地址会公开显示在商店页上**。不想暴露住址就填办公地址或公司注册地址，但要和后面上传的证明一致。
2. **个人信息**：法定姓名、法定地址、联系电话，全部按身份证填。
3. **上传身份证**正反面。
4. **上传地址证明**：信用卡账单最稳。
   - 账单上要能看清**姓名 + 通信地址**；卡号、交易明细可以遮挡。
   - 实测经验：**地址一律填身份证上的地址**，账单地址也对齐它。填现居住地 + 租房合同，很容易被判「无法证明您居住在此地址」打回两次。
5. 提交，等 1–3 天。通过后控制台会显示已验证。

## 4. 打包

```bash
bash scripts/package.sh
```

生成 `dist/cover-lightning-rod-1.3.2.zip`。三条硬规则：

- `manifest.json` 必须在 zip **根目录**，不能套一层文件夹（本脚本已处理）。
- 版本号只能往上加，**永久不能回退或复用**。改完代码记得改 `manifest.json` 的 `version`。
- 不能有远程代码（本项目所有 JS 都在包内，符合）。

## 5. 新建商品

控制台 → **新增项目 / New item** → 上传 zip → 进入资料页。

上传后左侧出现几个分区，必须全部填完「提交审核」按钮才会亮：**商品详情 / 隐私权 / 分发**。

## 6. 商品详情（可直接复制）

**名称**（≤45 字符）

```
封面避雷针
```

> 这个名字由 manifest 的 `name` 字段决定，**后台不能改成别的**。想让英文用户看到英文名，用「本地化商品详情」：加一条 `English (United States)` 条目，标题填 `Clickbait Cop`。中文区显示「封面避雷针」，英文区显示 `Clickbait Cop`，两者并存。

**简介**（≤132 字符）

```
把 YouTube、B站、抖音的封面换成视频里真实的画面，不再被夸张封面和 AI 生成的假封面骗进去。
```

**详细描述**

```
标题党封面看烦了？这个插件把封面换成视频里真实的那一帧。

■ 覆盖三个站点
YouTube、哔哩哔哩、抖音（含抖音精选、搜索页、个人主页）。

■ AI 生成的假封面也一起失效
现在越来越多封面是 AI 画的、或者拿生成图拼出来的，跟视频内容毫无关系。
本插件不做 AI 检测，也不需要检测——它直接把封面换成视频里真实的画面，
所以不管是夸张、摆拍还是 AI 生成的封面，你看到的都是视频本身。

■ 三档取帧
前段 25% / 中段 50% / 后段 75%，默认取中段。中段的画面通常最能代表视频真实内容。

■ 不下载视频
不下载、不转码、不上传。取的是平台自己为进度条预览生成的图像，本地裁剪后替换封面。
YouTube 直接用平台自动生成的三帧截图，速度最快。

■ 可随时还原
总开关一关，立刻恢复原封面；也可以按站点单独关。

■ 隐私
不收集任何个人数据，不向开发者服务器发送任何信息。
裁剪结果只存在你自己浏览器的本地缓存里，最多 1500 条，卸载插件即清除。

■ 已知限制
· 极短视频、图文、直播、广告等没有预览图的视频，会保留原封面
· 抖音精选顶部大图放大约 4 倍，会略糊（平台预览图本身只有 240×136）
· B 站多 P 视频只取第 1 集的画面
· YouTube Shorts 是竖版，为避免变形不做替换

■ English

Clickbait Cop swaps clickbait thumbnails for real frames taken from the video itself, so you can tell what a video is actually about before clicking it. That covers the AI-generated covers too — the ones that have nothing to do with the video behind them. There is no detection step: once the thumbnail is replaced by a real frame, a fake cover simply stops working. It works on YouTube, Bilibili and Douyin, and it reuses the preview images those platforms already generate for their progress bars — nothing is downloaded, transcoded or uploaded.

Pick the early, middle or late frame, toggle each site separately, and switch everything off to get the original covers back instantly. Everything runs locally in your browser: no account, no tracking, no data leaves your device.

开源地址：https://github.com/hiyanyang/clickbait-cop
```

> ⚠️ **不要在后面再挂一串 `keywords: xxx, xxx`**。Chrome 商店政策里的 "Keyword spam" 明确禁止堆砌关键词，塞得越多越容易被拒。想提高英文搜索命中率，正确做法是让关键词**自然出现在句子里**（上面那段已经包含 clickbait / real frame / thumbnail / YouTube / Bilibili / Douyin），而不是列成清单。

**类别**：工具 / Tools
**语言**：中文（简体）。可再加一条 `English (United States)` 本地化条目，标题填 `Clickbait Cop`，正文复制上面那段英文——中文区显示「封面避雷针」，英文区显示 `Clickbait Cop`。

**图标**：上传 `icons/128.png`
**截图**：上传 `docs/screenshots/` 下两张（1280×800）。
YouTube 那张需要你自己在真实 YouTube 页面截一张 1280×800 的——开发机访问不了 Google，我没有可用的真图，**不要拿模拟图冒充**。

可选加分项：小宣传图 440×280、顶部宣传图 1400×560（有助被推荐位收录）。

## 7. 隐私权表单（可直接复制）

**单一用途说明**

```
把视频网站上的封面替换为同一视频中真实画面的截图。
三个站点是同一功能的不同站点适配，不是多个用途。
```

**权限理由**（逐条填，空着或写套话会被拒）

| 权限 | 填写内容 |
|---|---|
| `storage` | 保存总开关、站点开关、取帧档位三项本地设置，不同步到任何服务器。 |
| `*://*.bilibili.com/*` | 在 B 站页面读取视频卡片的链接与封面元素以替换封面；并用于请求平台公开的 videoshot 接口获取该视频的预览图。 |
| `*://*.douyin.com/*` | 在抖音页面读取视频卡片与封面元素以替换封面。 |
| `https://*.hdslb.com/*` | 下载 B 站提供的预览图（雪碧图），在本地裁剪出目标帧。图片不上传到任何服务器。 |
| `https://*.douyinpic.com/*`、`https://*.byteimg.com/*`、`https://*.ibyteimg.com/*` | 下载抖音提供的预览图（雪碧图），在本地裁剪出目标帧。 |
| 内容脚本运行于抖音页面环境（MAIN world） | 抖音的预览图数据由页面自身通过带签名接口加载。为避免额外发起带签名的请求，扩展在页面环境内读取页面**已经加载到**的这部分数据，不修改、不拦截、不转发任何请求。 |

**数据使用声明**（勾选项）

- 是否收集个人身份信息：**否**
- 是否收集健康、财务、认证信息：**否**
- 是否收集位置信息：**否**
- 是否收集网页浏览记录：**否**（只是就地替换封面，不上报任何页面内容）
- 是否向第三方出售或转让数据：**否**
- 是否将数据用于与核心功能无关的用途：**否**

**隐私政策 URL**：填你的 GitHub Pages 地址，形如
`https://hiyanyang.github.io/clickbait-cop/privacy.html`

**认证声明**：勾选「我遵守 Chrome 应用商店开发者计划政策」。

## 8. 分发设置

| 选项 | 含义 | 建议 |
|---|---|---|
| 公开 Public | 商店可搜到、可安装 | 想获客就选这个 |
| 不公开 Unlisted | 只有拿到链接的人能装，搜不到 | 想先小范围测试，审核一样严格 |
| 私有 Private | 仅指定 Workspace 账号可装 | 团队内部用 |

地区：默认全部。免费、无内购，所以「定价」一栏不用管。

## 9. 提交审核

1. 点 **提交审核 / Submit for review**。
2. 首次发布会进人工审核。宽 host 权限 + 修改第三方页面外观这两点会让审核更细，**做好等 1–2 周的准备**。
3. 拒审邮件会写明违反哪条政策。改完重新上传，版本号 +1，当天可以再提。

常见拒审与本项目对应改法：

| 拒审理由 | 改法 |
|---|---|
| 权限与代码不符（列了没用的权限） | 本项目只声明 `storage`，没有多余权限，一般不会中 |
| 缺少隐私政策或政策与实际不符 | 用第 7 节的文案，政策里写的内容必须和真实行为一致 |
| 单一用途不明确 | 用第 7 节那句话，别写「提升浏览体验」这类空话 |
| 远程代码 | 本项目无，全包内 |
| 功能无法判断 / 页面打不开 | 审核员多半在海外，**访问不了抖音和 B 站**。这是本插件最大的不可控点，见第 11 节 |

## 10. 上架之后

- 发版：改 `manifest.json` 的 `version` → `bash scripts/package.sh` → 控制台上传新 zip → 提交审核。更新审核通常 1–2 天。
- Chrome 会在几小时内自动把新版本推给用户（手动可在 `chrome://extensions` 点「更新」）。
- 版本号不能回退，所谓「回滚」只能是发一个功能更少的更高版本。

## 11. 本插件专属风险（务必知道）

1. **名称里的商标**：`封面避雷针` 本身不含平台名，是安全的。但简介、详细描述里出现了 YouTube / B站 / 抖音 —— 描述里做「兼容性说明」通常没问题，**不要**在名称或图标里使用它们的 logo。Google 不主动拦，但平台方可以投诉下架（Netflix Party 因被 Netflix 施压改名 Teleparty 就是先例）。
2. **审核员访问不了目标站点**：抖音和 B 站对海外 IP 有限制，审核员很可能打不开页面，被判「功能无法确认」。对策：详细描述里把功能讲清楚，截图放真实页面（已备），必要时在「测试说明」里写明「本站需中国网络环境」。
3. **抖音的页面数据读取**（`world: MAIN` 的内容脚本）：属常规互操作手段，同类插件长期在架，但审核可能来问，第 7 节已准备好说明文案。
4. **上游接口变化**：B 站 `videoshot` 若加风控或改为需要签名，链路会静默失效（表现为全部保留原封面，不报错）。这不是商店层面的事，但要有心理准备。
5. **宽 host 权限**：`*://*.bilibili.com/*`、`*://*.douyin.com/*` 会触发深度审核。如果审核卡住，可考虑收窄到具体子域再提交。
